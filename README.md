# Nova página para o GLAM Museu Paulista

Proposta de página GLAM do **Museu Paulista** para apresentação e organização de conteúdos relacionados à atuação do museu nos projetos Wikimedia.

## Sobre o projeto

Este projeto apresenta uma proposta de interface para a página **Wikipédia:GLAM/Museu Paulista**, desenvolvida em HTML e CSS.

A proposta utiliza uma estrutura visual baseada em blocos de conteúdo, imagens e elementos de navegação, com uma apresentação minimalista, responsiva e alinhada à identidade visual do Museu Paulista.

## Conteúdos

A página apresenta conteúdos relacionados a:

* Wikipédia
* Wikimedia Commons
* Wikidata
* Escopo do projeto
* Projeto Novo Museu do Ipiranga
* Acompanhamento
* Repercussão midiática

## Tecnologias

* HTML5
* CSS3

As imagens e demais mídias utilizadas na proposta podem ser provenientes do **Wikimedia Commons**.
